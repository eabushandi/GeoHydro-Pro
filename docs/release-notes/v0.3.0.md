# GeoHydro Pro 0.3.0 — Phase 3: Advanced GIS and Spatial Analysis

Development pre-release. Not a production release, and not certified for engineering
use.

## New

**Grid mathematics** (`docs/GRID_MATH.md`)

* Grid calculator on up to four grids (A–D) with math functions, `where`, `isblank` and
  `fillblank`; grids on different geometries are resampled to a common one.
* Moving-window filters (mean, median, min, max, range, std, high-pass, Gaussian) that
  never fill blanks.
* Slope, aspect and hillshade (Horn 1981), curvature (Zevenbergen–Thorne 1987).
* Profiles along typed vertices or a line feature, with CSV export.
* Volumes (trapezoidal, Simpson 1/3, Simpson 3/8) and cut/fill against a level or another
  grid.
* Blanking and clipping by polygons.

**GIS data** (`docs/GIS.md`)

* Vector import and export: Shapefile (also zipped), GeoJSON, GeoPackage, KML/KMZ,
  FlatGeobuf. GML, DXF, GPX and MapInfo are readable but untested.
* Vector processing: reproject, buffer, clip, dissolve, area/length fields, repair. Each
  creates a new layer and is recorded in the history.
* Geodesic areas and lengths for longitude/latitude data.
* Raster import as grids (values) or as base-map images (colours), GeoTIFF export.
* Point density: kernel density (5 kernels, bandwidth rules, weights) and point counts.

**Maps**

* Vector and image layers with single, categorized and graduated symbology; opacity,
  visibility and order for every layer.
* Legend, inset location map, latitude/longitude graticule, text boxes and logo.
* TIFF export with resolution tag; PDF with embedded TrueType fonts.

**Editing**

* Undo and redo (Ctrl+Z / Ctrl+Y), 30 steps, covering imports, grid math and all map edits.

**Windows**

* Installer and portable zip built by CI, with a self-test of the frozen build, silent
  install and uninstall.
* GIS demo project with synthetic sample data.
* Installation and troubleshooting guide (`docs/WINDOWS_INSTALL.md`).

## Compatibility

* Project files are now format v3. Files from 0.1 and 0.2 open and are upgraded in memory;
  the file on disk is unchanged until you save. Older versions cannot open v3 files.
* All Phase 1 and Phase 2 features are unchanged.

## Validation

318 automated tests (179 from Phases 1–2, all still passing). Slope, aspect and hillshade
are compared with `gdaldem`, kernel density with scikit-learn, volumes with analytic
integrals, and geodesic measures with analytic and equal-area references. Results are in
`docs/TEST_RESULTS.md`.

## Known limitations

* Tested on Windows Server CI images only, not interactively on desktop Windows 10/11.
* The build is not code-signed, so Windows SmartScreen will warn.
* All sample data are synthetic.
* Surfer grid formats are not yet checked against files written by Surfer.
* No web tile base maps. LAS/LAZ point clouds and 3-D surfaces moved to Phase 4.
* Kernel density has no edge correction; aspect on projected grids is relative to grid
  north.
