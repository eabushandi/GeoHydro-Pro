# Sample datasets (synthetic)

All files are **synthetic**, generated by `generate_samples.py` from documented analytic
functions with a fixed seed (20261119). They are not field observations. Because the
generating functions are known, they double as reference data for future numerical
validation (e.g. interpolation error against the true surface).

Coordinates: WGS 84 / UTM zone 39N (EPSG:32639), a 10 km × 10 km window starting at
E 440000, N 2885000, unless stated otherwise.

| File | Format features | Content |
|---|---|---|
| `terrain_survey_utm39n.csv` | comma, header | 300 survey points. `z = 4 + 6u + 3v + 22·G(0.35,0.60,0.12) + 11·G(0.75,0.30,0.08) − 6·G(0.60,0.75,0.10) + N(0, 0.15)` with `u=(x−440000)/10000`, `v=(y−2885000)/10000`, `G(a,b,s)=exp(−((u−a)²+(v−b)²)/(2s²))` |
| `groundwater_wells.xlsx` | Excel, two sheets (`Wells`, `Notes`), column names with units | 60 wells: water level `1.5 + 4(1−u) + 1.2·G(0.4,0.5,0.15) + N(0, 0.05)` m AMSL; TDS mg/L |
| `bathymetry_nearshore.xyz` | whitespace, no header | 2000 soundings; depth deepens offshore with a sand bar at 600 m |
| `field_readings_with_errors.csv` | semicolon delimiter, decimal comma | 40 rows with deliberate problems: blank Z, `-9999`, `n/a`, a typo `4521x88`, `NaN`, one duplicate location with different Z, one exact duplicate. Expected QC: 35 usable, 5 excluded, 2 duplicate groups |
| `stations_wgs84.dat` | tab delimited, geographic (EPSG:4326) | 50 sea-surface temperature stations; one latitude typo (126.05°) outside the valid range |
| `contaminant_survey.txt` | `#` comment lines, whitespace, header | 80 benzene samples (µg/L), Gaussian plume `850·exp(−r²/(2·700²)) + |N(0,2)|` |
| `sample_project.ghproj` | project file | terrain survey + monitoring wells, CRS EPSG:32639 |

Regenerate with `python samples/generate_samples.py`.
