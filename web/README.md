# Web application and API (planned)

Status: **planned** (web foundation after the desktop foundation; full web application in Phase 7).

Planned stack: React + TypeScript + Vite + MapLibre GL JS + Three.js (frontend), FastAPI (backend).
The backend will import `geohydro.engine` and `geohydro.project` directly, so web
processing uses exactly the same algorithms and the same `.ghproj` format as the desktop.
No web code exists yet.
