# Changelog

Each version has detailed release notes in `docs/release-notes/`, test results in
`docs/TEST_RESULTS.md`, and a Windows installer, portable zip and self-test report attached
to its GitHub release. The release procedure is in `docs/RELEASING.md`.

## 0.3.0 — 2026-11-20 — Phase 3: Advanced GIS and Spatial Analysis

Grid calculator, filters, slope/aspect/hillshade, curvature, profiles, volumes and cut/fill;
vector import, export and processing; raster import as grids or base-map images; point
density; GIS map layers with symbology, legend, inset, graticule, logo and text boxes; TIFF
export and embedded PDF fonts; undo/redo; project format v3; Windows installer. 318 tests.
See `docs/release-notes/v0.3.0.md`.

## 0.2.0 — 2026-11-20 — Phase 2: Core Mapping

Eight gridding methods including genuine Ordinary and Universal Kriging, variograms,
cross-validation, Surfer and ESRI grid files, contour, filled contour, colour relief and
post maps, map page view and export, project format v2. 179 tests. No separate release
notes file was written for this version; see `docs/DEVELOPMENT_LOG.md`.

## 0.1.0 — 2026-11-19 — Phase 1: Foundation

Desktop shell, data import wizard with quality control, project format v1, CRS and units
handling, Windows CI. 88 tests. See `docs/DEVELOPMENT_LOG.md`.
